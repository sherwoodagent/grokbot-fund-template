# Routines (create disabled; the bot enables them)

| Name | Schedule | Prompt |
|---|---|---|
| desk-pulse | Weekdays 08:00 owner local time | "If setup isn't done, stay silent. **First, check the login:** the CLI refreshes the 1-hour `/sources` token itself for 7 days, so re-login is weekly, not every run. Run `sherwood sources status`; if `auto_refresh` is false (the 7-day refresh token ran out), re-login with the two-step `sherwood sources login --address <wallet>` → sign → `--signature 0x…` (fund-setup step 8). A 401 from a `sources` command comes after the CLI's own refresh attempt: re-login once (sign-only: the two-step; if no one can sign unattended, ask the owner). A 403 means the wallet is no longer approved: tell the owner and stop. Then pull `sources get calendar`, `prices`, `liquidity` and `morpho`. If no proposal is open and something is worth drafting, run the `propose` skill up to the owner-yes step. Message only if there's a draft or a decision. Otherwise stay silent." |
| proposal-watch | Every 10 minutes while the proposal is Pending or in GuardianReview (the review is 30 min on 4663), hourly after that; enabled only while a proposal is open | "**First, check the `/sources` login** the same way as desk-pulse (the CLI refreshes the 1-hour token itself; re-login only when `auto_refresh` is false or on a 401 after its refresh; 403 = no longer approved, tell the owner and stop). Then run the `watch` skill. Message only on a state change or a needed decision. Disable yourself when the proposal is terminal." |

**The weekly re-login needs a signer that can sign without a human.** A sign-only wallet re-logs in with the two-step about once a week. If the agent wallet asks a person to approve each signature, the routine can't log in on its own: it messages the owner with the message to sign and waits, instead of guessing or skipping the re-login. A routine may pay for research within the owner-set daily budget (`research.daily_budget_usd`); beyond it, it messages the owner instead of paying (`research-byok`).
